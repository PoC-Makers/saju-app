# 학습 흐름 정리 (Learning Recap)

프로젝트를 **공부하며 만드는 과정** 자체를 기록으로 남기는 스킬. 커밋 히스토리가 "코드가 어떻게 바뀌었나"라면, 이 문서는 **"내가 무엇을 이해했고 어디서 막혔나"**를 남긴다. 나중에 다시 읽으면 학습 흐름이 회상되도록.

기준 톤은 코드앤버터 인수인계 가이드(`메시지발송_프로세스_인수인계가이드.pdf`) — **쉬운 설명 → 점진 심화**, 비유·예시·콜아웃·표를 적극 사용.

## 언제 쓰나

- 사용자가 명시적으로 요청: "학습 기록 정리", "이번 단계 회고 PDF", "지금까지 배운 것 문서로"
- 한 단계(예: Step 0 모노레포 뼈대)를 끝냈을 때 → "이번 단계 학습 기록 남길까요?"라고 **먼저 제안**하고 확정 후 작성

## 무엇을 담나 (대화에서 수집)

이번 회차의 대화를 훑어 아래를 뽑는다. **꾸며내지 말고 실제로 오간 내용만.**

1. **한 일** — 이번 세션/단계에서 실제로 달성한 것
2. **배운 개념** — 새로 설명한 개념(예: 모노레포, Turborepo, 진태양시). 쉬운 설명 + 비유
3. **막힌 지점 & 질문 (Q&A)** ★ 이 문서의 핵심 — 사용자가 헷갈려하거나 물어본 것을 **질문 원문 그대로 → 그때 이해한 답**으로. (예: "RN/Flutter 웹이 웹뷰인가?", "Neon이 뭐지?", "왜 백엔드가 없어 보이지?")
4. **내린 결정** — 이번에 정한 것 + 이유 + 제쳐둔 대안 (예: Yarn Berry 채택, NestJS 선택)
5. **새 용어** — 이번에 처음 나온 용어를 한 줄로
6. **다음 단계** — 이어서 할 일

> 5~7개 섹션이 기본. 이번 회차에 없는 섹션(예: 결정이 없었다면 "5. 결정")은 통째로 뺀다. 억지로 채우지 않는다.

## 정리 구조 (권장 섹션 순서)

`template.html`의 순서를 그대로 따른다:

```
표지 → 인트로("이 기록은?") → 1.한눈에 → 2.배운 개념 → 3.따라한 과정(단계별)
→ 4.막힌 지점 & 질문(Q&A) → 5.내린 결정 → 6.새 용어 → 7.다음 단계 → 푸터
```

## 톤·양식 규칙 (기준 문서 준수)

- **쉬운 말 먼저, 전문용어는 그 다음.** 초보가 읽어도 이해되게.
- **비유 콜아웃**(`callout analogy`, 🏣)으로 개념을 일상에 빗대기. 남발 금지 — 진짜 헷갈릴 만한 개념에만.
- **핵심 콜아웃**(`callout key`, 💡)으로 꼭 기억할 한 줄.
- **예시 콜아웃**(`callout example`, 초록 점선)으로 구체 시나리오/명령 예.
- **표**로 용어·결정·비교를 압축.
- **단계는 원형 번호 뱃지**(`ol.steps`)로, 각 단계에 "왜 했는지(why)"를 붙인다.
- **Q&A 블록**은 질문을 미화하지 말고 사용자가 실제로 물은 톤 그대로. 답엔 "왜 헷갈렸는지"까지.
- **식별자·명령은 monospace**(`<code>`, `<pre>`).
- **솔직하게** — 아직 안 정한 것/모르는 것은 그대로 "미정"이라 적는다.
- 이모지는 기준 문서처럼 마커로만 소량(💡 🏣). 과용 금지.

## 만드는 절차 (HTML → PDF)

1. **출력 폴더 준비**: `docs/recaps/` (없으면 생성)
2. **HTML 작성**: `template.html`을 복사해 자리표시자 `[[...]]`와 예시 블록을 실제 내용으로 교체.
   저장: `docs/recaps/학습기록_{YYMMDD}_{주제슬러그}.html`
3. **PDF 변환** (헤드리스 Chrome — 자립형 HTML이라 외부 리소스 불필요):
   ```bash
   HTML="$HOME/workspace/saju-app/docs/recaps/학습기록_{YYMMDD}_{주제}.html"
   OUT="${HTML%.html}.pdf"
   CHROME=""
   for c in \
     "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
     "/Applications/Google Chrome Canary.app/Contents/MacOS/Google Chrome Canary" \
     "/Applications/Chromium.app/Contents/MacOS/Chromium"; do
     [ -x "$c" ] && CHROME="$c" && break
   done
   "$CHROME" --headless=new --disable-gpu --no-pdf-header-footer \
     --print-to-pdf="$OUT" "file://$HTML"
   ```
4. **검증**: `qlmanage -t -s 1400 -o <임시폴더> "$OUT"`로 1페이지 썸네일을 만들어 렌더링(한글 폰트·레이아웃)을 눈으로 확인.
5. **결과 안내**: 생성된 HTML·PDF 경로를 알려주고, 필요하면 `open "$OUT"`로 미리보기.

## 파일 규칙

| 항목 | 규칙 |
|------|------|
| 출력 폴더 | `docs/recaps/` |
| 파일명 | `학습기록_{YYMMDD}_{주제슬러그}.{html,pdf}` (예: `학습기록_260812_모노레포뼈대.html`) |
| 원본(SoT) | HTML. PDF는 언제든 재생성 가능 |
| 커밋 | **개인화 문서라 `docs/recaps/`째로 gitignore** — 추적 안 함 (HTML이 원본, PDF는 재생성) |
